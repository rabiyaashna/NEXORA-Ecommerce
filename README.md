# NEXORA – E-Commerce Website

**Technology, Within Reach.**

NEXORA is a modern, responsive electronics and gadgets e-commerce website designed to provide a simple and user-friendly online shopping experience.

## Project Information

- **Project Name:** NEXORA
- **Project Type:** E-Commerce Website
- **Industry:** E-Commerce / Retail
- **Training:** Zelvora Industry Labs
- **Program:** 4-Week Industry Training
- **Project:** Week 4 – E-Commerce Website

## Features

- Modern and responsive homepage
- Electronics and gadgets product collection
- 50 products across multiple categories
- Product search functionality
- Category-based filtering
- Price sorting (low to high and high to low)
- Add to Cart interface
- Individual product images
- Modern user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Product Categories

- Audio
- Wearables
- Accessories
- Smartphones
- Tablets
- Laptops
- Monitors
- Gaming
- Smart Home


## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `frontend/index.html` using the Live Server extension.
4. Explore the NEXORA e-commerce website.

## Project Objective

The objective of this project is to develop a responsive e-commerce storefront that showcases electronic products and demonstrates frontend web development concepts.
